نصب روی Cloudflare

ورود موقت می‌کنی، نام‌ها را انتخاب می‌کنی، نصب خودکار انجام می‌شود.

با یک کلیک به Cloudflare وصل می‌شوی. دسترسی فقط ۱۰ دقیقه زنده است و هیچ فایلی از حساب گیت‌هاب تو خوانده نمی‌شود.

بدون توکنورود با تأیید خود Cloudflare انجام می‌شود، نه با کپی توکن.
بدون گیت‌هاباسکریپت آماده از سمت ما آپلود می‌شود.
نشست کوتاهبعد از ۱۰ دقیقه دسترسی خودبه‌خود باطل می‌شود.
این صفحه به سرور نصب متصل می‌شود. اگر آدرسش را نمی‌دانی، پایین صفحه بخش «آدرس سرور نصب» را ببین.

    سؤال‌های رایج

    چرا ورود موقت و نه توکن API؟

    توکن API باید دستی ساخته و کپی شود و معمولاً عمر طولانی دارد. در این روش با Authorization Code + PKCE وارد می‌شوی، دسترسی فقط روی سرور نصب نگه داشته می‌شود، هرگز به مرورگر برنمی‌گردد و بعد از ۱۰ دقیقه منقضی می‌شود.

    چه دسترسی‌هایی گرفته می‌شود؟

    فقط سه چیز: خواندن حساب‌ها، ساخت فضای KV و آپلود اسکریپت ورکر. در صفحه‌ی تأیید کلودفلر دقیقاً همین‌ها را می‌بینی و می‌توانی رد کنی.

    چرا فایل از گیت‌هاب خوانده نمی‌شود ولی نصب انجام می‌شود؟

    اسکریپت آماده داخل سرور نصب نگه‌داری می‌شود و همان‌جا با API کلودفلر آپلود می‌شود. حساب گیت‌هاب تو هیچ نقشی در نصب ندارد.

    آدرس سرور نصب

    اگر آدرس سرور نصب را می‌دانی، اینجا بگذار. در همین مرورگر ذخیره می‌شود و هیچ‌جا ارسال نمی‌شود.

    🔒

    امنیت

    • هیچ توکن یا رمزی در این صفحه ذخیره نمی‌شود؛ نه در حافظه‌ی مرورگر و نه در آدرس صفحه.
    • دسترسی کلودفلر فقط روی سرور نصب می‌ماند و بعد از ۱۰ دقیقه یا پایان نصب باطل می‌شود.
    • رمز پنل به‌صورت Secret رمزنگاری‌شده روی ورکر می‌نشیند و در پاسخ‌ها برگردانده نمی‌شود.
    • هیچ اسکریپت یا فونت خارجی بارگذاری نمی‌شود (CSP سخت‌گیرانه).
