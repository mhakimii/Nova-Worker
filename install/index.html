ساخت API Token در Cloudflare

روی دکمه بزن؛ صفحه‌ی ساخت توکن با دسترسی‌های لازم از قبل پر می‌شود. فقط دکمه‌ی Create Token را بزن.

دسترسی‌ها: Workers Scripts (Edit) · Workers KV Storage (Edit) · Account Settings (Read)

ساخت توکن در Cloudflare ↗
توکن فقط یک‌بار نمایش داده می‌شود. همان لحظه کپی کن — در مرحله‌ی ۳ لازمش داری.

پیدا کردن Account ID

در داشبورد کلودفلر، اکانتت را باز کن؛ Account ID پایین صفحه‌ی Overview (یا در آدرس صفحه) نوشته شده است.

باز کردن داشبورد ↗

۴

اجرای نصب

در صفحه‌ی Actions روی Run workflow بزن. نام ورکر را می‌توانی همان nova-worker بگذاری یا عوض کنی.

اجرای Deploy در GitHub ↗ دیدن اجرا‌ها

در این مرحله به‌صورت خودکار: فضای KV ساخته می‌شود، ورکر منتشر می‌شود و رمز مدیر تنظیم می‌شود.

✓

بعد از نصب

در پایان اجرا، آدرس ورکر در بخش Summary همان اجرا نوشته می‌شود؛ چیزی شبیه این:

https://nova-worker.<subdomain>.workers.dev

صفحه‌ی ورود: همان آدرس + /login — پنل: /admin — رمز: همان ADMIN_PASSWORD.

برای به‌روزرسانی بعدی، فقط کافی است اکشن deploy را دوباره اجرا کنی. تنظیمات و کاربران در KV باقی می‌مانند.
اگر خطا گرفتم چه کار کنم؟

Authentication error / 10000: توکن ناقص است یا Account ID اشتباه. توکن را با همان لینک مرحله ۱ دوباره بساز.

KV namespace not found: توکن دسترسی Workers KV Storage ندارد؛ مقدار Edit لازم است.

Secret خالی است: نام Secret را دقیقاً مثل مرحله ۳ بنویس (حروف بزرگ).

Worker name invalid: فقط حروف کوچک انگلیسی، عدد و خط تیره مجاز است.

این صفحه هیچ رمز یا توکنی دریافت نمی‌کند؛ همه‌ی عملیات داخل GitHub و Cloudflare انجام می‌شود.
