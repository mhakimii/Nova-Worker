یک کلیک، بدون توکن API، بدون کامند.

با دکمه‌ی زیر، Cloudflare خودش مخزن را می‌گیرد، فضای KV را می‌سازد و ورکر را منتشر می‌کند.

چه اتفاقی می‌افتد

  1. به Cloudflare وارد می‌شوی و اجازه‌ی دسترسی به GitHub را می‌دهی.
  2. اکانت و نام ورکر را انتخاب می‌کنی.
  3. رمز مدیر (ADMIN) را وارد می‌کنی — همین رمز، رمز ورود پنل است.
  4. Cloudflare مخزن را در اکانت گیت‌هاب خودت کپی می‌کند، KV را می‌سازد و ورکر را منتشر می‌کند.
رمز را همین حالا آماده کن: حداقل ۱۲ کاراکتر، ترکیبی از حروف بزرگ و کوچک، عدد و نماد. رمز کوتاه یا تکراری نگذار.
۲

بعد از نصب

آدرس ورکر را در داشبورد Cloudflare، بخش Workers & Pages می‌بینی؛ چیزی شبیه این:

https://nova-worker.<subdomain>.workers.dev

  • صفحه‌ی ورود: همان آدرس + /login
  • پنل مدیریت: /admin
  • رمز ورود: همان مقداری که در مرحله‌ی نصب به‌عنوان ADMIN وارد کردی
تغییر رمز بعداً: Workers → ورکر خودت → Settings → Variables and Secrets → مقدار ADMIN را ویرایش کن.
۳

امنیت

  • هیچ توکن API در این صفحه یا در مرورگر تو قرار نمی‌گیرد؛ احراز هویت کاملاً با Cloudflare است.
  • رمز مدیر به‌صورت Secret رمزنگاری‌شده روی ورکر ذخیره می‌شود، نه در کد و نه در گیت‌هاب.
  • هیچ اسکریپت یا فونت خارجی در این صفحه بارگذاری نمی‌شود (CSP سخت‌گیرانه).
  • کد این پروژه عمومی است؛ رمزها و داده‌های کاربران هرگز داخل ریپو نیستند.
مسیر حرفه‌ای: نصب با GitHub Actions (اختیاری)

اگر می‌خواهی دیپلوی از داخل ریپوی خودت انجام شود، این مسیر را استفاده کن. به یک توکن Cloudflare با دسترسی Workers Scripts (Edit) و Workers KV Storage (Edit) نیاز داری.

اگر خطا گرفتم

  • Authentication error: توکن ناقص است یا Account ID اشتباه.
  • KV namespace not found: توکن دسترسی Workers KV Storage (Edit) ندارد.
  • Secret خالی است: نام Secret را دقیقاً با حروف بزرگ بنویس.
  • نام ورکر نامعتبر: فقط حروف کوچک انگلیسی، عدد و خط تیره.
