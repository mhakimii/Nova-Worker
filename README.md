# Nova Worker

پنل مدیریت وورکر کلودفلر — بازنویسی از صفر، با UI فارسی.

> **وضعیت: مرحله ۰ — اسکلت پروژه.** هنوز هیچ منطق پنلی نوشته نشده است. این ریپو فقط ساختار، قواعد و نقطه‌ی شروع را تثبیت می‌کند.

## ساختار

| مسیر | کار |
| --- | --- |
| `src/index.js` | نقطه‌ی ورود Worker و روتر اصلی |
| `wrangler.toml` | تنظیمات اجرا و دیپلوی |
| `.dev.vars.example` | الگوی متغیرهای محلی و رمزها |
| `docs/` | تصمیم‌های فنی (بعداً اضافه می‌شود) |

## اجرا

```bash
npm install      # نصب wrangler
npm run dev      # اجرای محلی روی http://localhost:8787
npm run deploy   # انتشار روی Cloudflare
```

بررسی سلامت پس از اجرا: `GET /health`

## قواعد این ریپو

1. **هیچ رمز، توکن یا کلیدی در ریپو کامیت نمی‌شود.** رمزهای محلی فقط در `.dev.vars` (که در `.gitignore` است) و رمزهای واقعی فقط در Secrets خود کلودفلر.
2. **`main` همیشه باید قابل اجرا باشد.** هر تغییر ناتمام روی شاخه‌ی جدا انجام می‌شود و بعد از بررسی، merge می‌شود.
3. **کد دیگران بدون بررسی وارد نمی‌شود.** هر تغییری که از بیرون می‌آید (PR، فایل، پچ) اول خوانده و تست می‌شود.
4. **بدون وابستگی اضافه.** تا وقتی یک کتابخانه واقعاً لازم نشده، به `package.json` اضافه نمی‌شود.

## نقشه‌ی راه پیشنهادی

- [ ] مرحله ۱ — اسکلت، روتر و صفحه‌ی ورود مدیر
- [ ] مرحله ۲ — ذخیره‌سازی تنظیمات و کاربران (KV یا D1)
- [ ] مرحله ۳ — مدیریت نودها و کانفیگ‌ها
- [ ] مرحله ۴ — پنل فارسی (لیست کاربران، آمار، تنظیمات)
- [ ] مرحله ۵ — تست، سخت‌سازی امنیتی و مستندسازی

## لایسنس

این پروژه از صفر نوشته می‌شود. اگر بعداً کدی از `cmliu/edgetunnel` یا هر پروژه‌ی دیگری منتقل شود، لایسنس و نام نویسنده‌ی اصلی همان بخش حفظ خواهد شد.
